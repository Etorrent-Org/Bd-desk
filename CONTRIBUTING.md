# Contribution

1. Créer une branche de travail.
2. Ajouter ou adapter les tests avec tout changement métier.
3. Exécuter `npm test` puis `npm run test:coverage`.
4. Ne jamais committer `.env`, base SQLite ou export de collection personnelle.
5. Documenter toute nouvelle route dans `docs/API.md` et `openapi.yaml`.
