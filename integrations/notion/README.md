# Notion

La base maîtresse de la collection reste BD Desk. Notion est une cible de publication/synchronisation, typiquement via n8n ou Make.

Schéma conseillé côté Notion :

- Titre
- Série
- Tome
- ISBN
- Éditeur
- Lu
- Wishlist
- Couverture
- BD Desk ID
- Dernière synchro

Utiliser `BD Desk ID` comme clé d'upsert et ne pas utiliser le nom d'album comme identifiant.
